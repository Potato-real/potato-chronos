# Bloom Valley Nursery Website
Sophia Learning – Introduction to Web Development
Touchstone 3: Visual Design and Responsive Layout

 Client
Bloom Valley Nursery, a local, family-owned plant nursery specializing in plants, trees, and gardening supplies for gardening enthusiasts and homeowners.

 Pages
- `index.html` – Homepage (hero, promos, staff picks, perks, categories)
- `gallery.html` – Product gallery with Add to Cart buttons and View Cart
- `about.html` – About the nursery, hours, and feedback/custom-order form
- `events.html` – Workshops, events, testimonials (custom page)

 Design System (strict limits)
- **Colors (exactly 4):**  
  Cream `#FFF8F0` · Brown `#6B3E26` · Peach `#D88C5A` · Charcoal `#2F2A26`
- **Fonts (exactly 2):**  
  Georgia (serif – headings) · system-ui / sans-serif (body & UI)
- **Layout:** Mobile-first Flexbox  
- **Media queries:** 640px (tablet) and 900px (desktop)
- **External CSS:** `css/styles.css` (linked on every page)
