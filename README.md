# Bloom Valley Nursery Website

**Sophia Learning – Introduction to Web Development**  
**Touchstone 3: Visual Design and Responsive Layout**

## Client
Bloom Valley Nursery – a local, family-owned plant nursery specializing in plants, trees, and gardening supplies.

## Pages
- `index.html` – Homepage (highlights, promos, staff picks, perks, categories)
- `gallery.html` – Product gallery with “Add to Cart” buttons and View Cart
- `about.html` – About the nursery, hours, and feedback/custom-order form
- `events.html` – Workshops, events, testimonials, and community involvement

## Design System
- **Colors (4):** Cream `#FFF8F0`, Brown `#6B3E26`, Peach `#D88C5A`, Charcoal `#2F2A26`
- **Fonts (2):** Georgia (serif headings) + system-ui / sans-serif (body)
- **Layout:** Mobile-first Flexbox with media queries at 600px and 900px
- **External CSS:** `css/styles.css`

## How to View
Open `index.html` in a browser or use any static-site host / GitHub Pages.

## GitHub Pages (optional)
1. Push this repository to GitHub
2. Settings → Pages → Deploy from main branch / root
